# Nunito

Source: https://github.com/google/fonts/tree/main/ofl/nunito
License: SIL Open Font License 1.1 (see OFL-Nunito.txt).

Regular (400), Bold (700), and ExtraBold (800) static TTF files were
instantiated from the official Nunito[wght].ttf using fontTools 4.65.0
with updateFontNames=True. Fonts are bundled for offline use in JavaFX.

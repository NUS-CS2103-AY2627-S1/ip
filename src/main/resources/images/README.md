# Robot artwork

`arin-avatar.jpg` is the unmodified image supplied by the project owner
for Arin's graphical interface. The supplied file was named `Ui.png`, but its
actual encoding is JPEG, so the bundled resource uses the `.jpg` extension.

The original source and license were not supplied. This illustration is
not claimed as original project artwork. The course screenshot is a
separate capture of the running application, saved as `docs/Ui.png`.

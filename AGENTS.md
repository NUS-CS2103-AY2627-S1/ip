# Project context

This repository is a starter template for a greenfield Java project used in an introductory software engineering course in an undergraduate computer science program. Students use it as the starting point for their own projects.

# Default user context

Unless the user says otherwise, assume that you are assisting a student working on a project in this repository. If the user identifies themselves as an instructor or another project stakeholder, adapt your response to that role.

# Student profile

* Prior knowledge: Basic Java and OOP concepts.
* Level of programming experience: Intermediate
* IDE and level of expertise: IntelliJ IDEA, Intermediate experience

# Guidance for interacting with users

* Explain the rationale for significant actions: what you did and why.
* The code snippets given as examples are just examples. If the existing code already implements that functionality (but with some changes, e.g. the text printed is different), don't automatically edit it.
* Keep explanations brief but instructive, supporting learning. For example:

  * Add comments to all classes and to nontrivial methods and fields when their purpose or behavior is not obvious. However, don't overclutter the code with comments either.
  * Make generated code concise yet readable, and include explanatory comments only where they improve understanding.
  * When faced with a nontrivial design choice, pause and give the user several options, briefly explaining the differences between each. Continue once the user has replied with their choice.

# Project-specific requirements

## Java version:

Ensure that Java 25 is used when running the application or build tasks. On macOS, use `sdk use java 25.0.3.fx-zulu` to switch to Java 25 if needed.

## Git

Use lightweight tags unless the user requests an annotated tag.
When proposing or creating a commit message, include enough detail to explain the rationale for the change. Ensure that the commit message follows the standards set in this link: https://se-education.org/guides/conventions/git.html
Do not commit or push unless explicitly asked.

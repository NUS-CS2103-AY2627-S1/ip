# Soya avatar provenance

Vincent requested an original soya-milk carton avatar. OpenAI's built-in
image-generation tool, used through ChatGPT/Codex, generated the PNG without
any reference images. It replaces the S text avatar, not the user avatar.
The asset is stored at `src/main/resources/images/soya-carton.png`.

## Generation prompt

> Use case: stylized-concept. Asset type: small chatbot profile avatar for a
> JavaFX desktop app. Generate a single original illustrated carton of soya
> milk with a friendly slightly sassy face, bold clean silhouette and simple
> chunky details legible at 36 pixels. Cream carton with plum and warm gold
> accents matching the app palette, folded carton top, tiny soybean illustration
> on carton, subtle three-quarter view. Center the entire carton on a genuinely
> transparent square background with a narrow clear margin. No lettering, no
> real brands, no logos, no watermark, no surrounding props. Produce a PNG
> asset and provide the saved local file path for integration into the project.

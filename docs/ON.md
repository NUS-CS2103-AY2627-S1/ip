# on

Finds all tasks that occur on the specified date

## Synopsis

on \<date to search\>

## Example usage

```
on 18/09/2026
```
finds deadlines ending on, and events running through 18/09/2026

Expected output:
```
Nyon! (Tasks on 18/09/2026:
1. [E][ ] sleep (from: 17 Sep 2026 1200 to: 20 Sep 2026 1200)
2. [D][ ] read (by: 18 Sep 2026 1200)
)
```

Panda User Guide

Panda is a desktop chatbot for keeping todos, deadlines, and events in one task list.

Enter a command in the chat box, then press Enter or select Send.

Quick start

Try these commands one at a time:

todo buy groceries
deadline submit report /by 2026-10-22 1800
event team meeting /from 2026-10-20 1400 /to 2026-10-20 1600
list

Command format

  • Use exactly one space between command parts.
  • Task numbers start at 1 and use the order currently shown.
  • Dates can be 2026-10-22 or 22/10/2026.
  • Times can be 1800, 18:00, or 6:00 PM.

Features

Add a todo

todo DESCRIPTION

Example: todo buy groceries

Add a deadline

deadline DESCRIPTION /by DATE [TIME]

Example: deadline report /by 2026-10-22 1800

Add an event

event DESCRIPTION /from DATE [TIME] /to DATE [TIME]

The end must be after the start.

Find tasks

find KEYWORD

Searches descriptions without considering letter case.

Update tasks

mark INDEX, unmark INDEX, or delete INDEX

Example: mark 2

View or exit

list shows all tasks. bye closes Panda.

Sort deadlines by date

Select Sort deadlines by date above the chat history. Use the Ascending/Descending button to choose the direction.

Only deadlines are sorted. Todos and events follow in the order they were added. While sorting is enabled, task numbers for mark, unmark, and delete refer to the displayed order.

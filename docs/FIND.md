# find

Finds all tasks that matches the search string

## Synopsis

find \<text to search\>

## Example usage

```
find sleep
```
finds tasks which contain the word `sleep`

Expected output:
```
Nyon! (
1. [E][ ] sleep (from: 01 Jan 1900 0000 to: 01 Jan 1900 0800)
)
```

---

```
find read
```
finds tasks which contain the word `read`

Expected output:
```
Nyon! (
1. [T][ ] read
2. [T][ ] read book
)
```

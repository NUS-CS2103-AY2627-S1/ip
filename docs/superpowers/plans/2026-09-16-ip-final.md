- [x] **Step 3: Add focused validation helpers**

Add private helpers to `Parser`:

```java
private static void validateStorageSafe(String... values)
        throws PavanmaxxerException {
    for (String value : values) {
        if (value.contains("|")) {
            throw new PavanmaxxerException(
                    "Task details cannot contain the | character.");
        }
    }
}

private static int countOccurrences(String text, String field) {
    int count = 0;
    int index = text.indexOf(field);
    while (index >= 0) {
        count++;
        index = text.indexOf(field, index + field.length());
    }
    return count;
}
```

Require exactly one `/by` for deadlines, exactly one `/from` and `/to` in that order for events, and call `validateStorageSafe` on every value before constructing a task.

# SE-EDU Java coding standard

Apply the conventions documented at https://se-education.org/guides/conventions/java/intermediate.html.

- Keep all classes in lower-case, project-specific packages.
- Use PascalCase for classes and enums, camelCase for methods and variables, and SCREAMING_SNAKE_CASE for constants.
- Use four-space indentation, K&R braces, explicit imports, and a maximum line length of 120 characters.
- Initialize variables near their declaration and keep them in the smallest reasonable scope.
- Use braces for all loop and conditional bodies.
- Write descriptive JavaDoc header comments for all classes and public methods; document non-trivial private methods.
- Keep comments in English and use American spelling.
- Add or update relevant JUnit tests after every code change, focusing on the highest-value methods and maintaining the project's 50% coverage target.

Use the linked SE-EDU guide and Google Java Style Guide for details not covered here.

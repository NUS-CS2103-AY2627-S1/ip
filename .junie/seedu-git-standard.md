# Skill: seedu-git-standard

## Overview
Based on https://se-education.org/guides/conventions/git.html

## Key Rules
- Use imperative mood in the subject line (e.g., "Add feature" not "Added feature").
- Separate subject from body with a blank line.
- Limit the subject line to 50 characters.
- Explain "what" and "why" in the body, not "how" (the code shows how).
- Reference issues if applicable.
- Use `Co-authored-by` trailer for collaborative work.

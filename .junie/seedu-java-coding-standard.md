# Skill: seedu-java-coding-standard

## Overview
Based on https://se-education.org/guides/conventions/java/intermediate.html

## Key Rules
- Use 4 spaces for indentation.
- Follow standard Java naming conventions.
- Use meaningful variable and method names.
- Keep methods short and focused on a single responsibility.
- Use Javadoc for all public classes and methods.
- Avoid overly complex logic within methods.
- Order class members logically (fields, constructor, methods).

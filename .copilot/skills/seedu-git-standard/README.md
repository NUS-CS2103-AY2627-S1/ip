seedu-git-standard

This skill documents the SE-EDU Git conventions for this repository (commit messages, tagging, pushing).

Guidance:
- Subject line: imperative tense, <50 characters.
- Body: explain why the change was made and any relevant tradeoffs.
- Wrap the body at 72 characters per line.
- Include Co-authored-by trailer only when authoring assistance mandates it.

Add automated checks (commit hooks or CI) later to enforce these rules.

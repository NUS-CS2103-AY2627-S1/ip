# SE-EDU Git Standard (project skill)

This skill captures and documents the repository-specific requirements to follow the SE-EDU Git conventions:
https://se-education.org/guides/conventions/git.html

Usage:
- All contributors and agents MUST follow the commit message format and workflow guidance when creating commits for this repository.
- Commit messages should have an imperative, short subject line (<=50 chars), optional body explaining what and why, and trailers when needed.
- Prefer lightweight tags; include Co-authored-by trailers for Copilot-created commits only when requested in commit policy.
- Do not push changes to remote without explicit permission from the repository owner or maintainer.

Note: This SKILL.md is a project-local guideline. CI hooks or commit-msg hooks may be added later to validate commit messages automatically.

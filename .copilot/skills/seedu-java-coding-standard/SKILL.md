# SE-EDU Java Coding Standard (project skill)

This skill documents and enforces the coding conventions described at:
https://se-education.org/guides/conventions/java/intermediate.html

Usage:
- Agents and contributors must follow the conventions when adding or modifying Java code in this repository.
- Public classes and nontrivial public methods must include Javadoc documentation.
- Naming, spacing, ordering of members, and other conventions from the referenced guide should be followed.

Note: This SKILL.md is a project-local guideline. Tools or CI jobs may be added later to automatically validate style against this standard.

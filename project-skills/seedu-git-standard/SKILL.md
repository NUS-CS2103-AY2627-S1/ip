# SE-EDU Git standard

Apply these rules to every proposed or created commit message in this repository. The authoritative source is the [SE-EDU Git conventions guide](https://se-education.org/guides/conventions/git.html).

- Write a subject in imperative mood, capitalize its first letter, omit a final period, and keep it preferably within 50 characters and never above 72.
- Add a body for non-trivial commits, separated by one blank line and wrapped at 72 characters. Use blank lines between paragraphs and bullets when useful.
- Explain what changed and why, not how. Describe the current situation in present tense, why it needs to change, what to do in imperative mood, and the rationale.
- Split unrelated changes into separate commits. Review the proposed message against the subject length, mood, capitalization, punctuation, body wrapping, and what/why requirements before committing.

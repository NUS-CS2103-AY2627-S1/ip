# Keep Code Simple

Complete the assigned task with the simplest clear solution that fits the existing codebase.

- Add only what the requirement needs; avoid speculative abstractions, unrelated refactors, duplicate logic, and unnecessary dependencies.
- Preserve existing behavior outside the requested scope.
- Before finishing, verify every requirement and run the relevant tests. Do not claim completion while required work remains.

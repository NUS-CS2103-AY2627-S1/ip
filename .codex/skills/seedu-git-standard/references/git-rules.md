# SE-EDU Git rules used in this repo

- Write every commit subject in the imperative mood.
- Capitalize the first word of the subject.
- Do not end the subject with a period.
- Prefer a subject length around 50 characters; keep the hard limit at 72.
- Add a body for non-trivial commits.
- Separate the subject and body with a blank line.
- Wrap commit-body lines at 72 characters.
- Use blank lines to separate body paragraphs.
- Explain WHAT changed and WHY it should change, not HOW the diff works.
- Use bullets in the body when that improves clarity.
- If the explanation becomes too long, split the work into smaller commits.
- Use meaningful kebab-case branch names, such as `refactor-ui-tests`.
- If the branch maps to an issue, prefer `issueNumber-keywords-from-title`.

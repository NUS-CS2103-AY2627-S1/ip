# Seedu Git Standard

Apply the [SE-Education Git conventions](https://se-education.org/guides/conventions/git.html)
to every future commit in this repository.

- Write an imperative, capitalized subject with no trailing period; prefer 50 characters and never exceed 72.
- Add a body for non-trivial commits, separated from the subject by a blank line and wrapped at 72 characters.
- Explain what changed and why, using present tense for the situation and imperative mood for the change. Do not explain implementation details that are already clear from the diff.
- Split unrelated changes into separate commits where practical.
- Do not commit or push unless the user explicitly requests it.

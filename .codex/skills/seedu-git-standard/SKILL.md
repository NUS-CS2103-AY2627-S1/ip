# SE-EDU Git standard

Follow these conventions for all future Git work in this project:

- Use a meaningful kebab-case branch name, with issue-number prefixes when an
  issue is being addressed.
- Give every commit an imperative, capitalized subject with no trailing period;
  aim for 50 characters and never exceed 72 characters.
- For non-trivial commits, separate the subject from a body, wrap body lines at
  72 characters, and use blank lines between paragraphs.
- Use the body to explain what changed and why. Describe the current situation,
  motivation, intended change, rationale, and other relevant information rather
  than narrating implementation details.
- Use bullets when they make a commit body easier to scan.

For the complete guidance, consult the
[SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html).

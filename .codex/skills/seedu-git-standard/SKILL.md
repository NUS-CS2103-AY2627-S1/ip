# SE-EDU Git Standard

Use this skill for every commit or proposed commit message in this repository. Follow the SE-EDU [Git conventions](https://se-education.org/guides/conventions/git.html).

For each commit:

- Write an imperative, capitalized subject with no trailing period; keep it near 50 characters and never over 72 characters. An applicable `scope:` or category prefix is allowed.
- For every non-trivial commit, separate the subject from a body with one blank line and wrap body lines at 72 characters.
- Use the body to explain what changed and why, in present tense for the current situation and imperative mood for the change. Do not explain implementation details that the diff already shows.
- Use blank lines between body paragraphs and bullets when they make the explanation clearer.
- If the explanation becomes too long, split the work into smaller commits.

Before committing, inspect the staged diff and verify that the message lets a reader judge the change without reading the diff.

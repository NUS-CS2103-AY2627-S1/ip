# SE-EDU Git Standard

This skill shares its rules with the Claude Code skill in `.claude/skills/seedu-git-standard/`,
so both tools hold the project to the same standard. The rules themselves, and the commands
that check history against them, live in `.claude/skills/seedu-git-standard/SKILL.md`. Read
that file and apply it.

The rules come from <https://se-education.org/guides/conventions/git.html> and cover the commit
message subject and body, and branch names. They apply to every commit and branch in this
project.

# SE-EDU Git Standard

Apply this skill before proposing a commit message, creating a commit, or naming a branch in this repository.

Read [references/standard.md](references/standard.md) completely. Inspect the exact changes included in the proposed commit, then write a message that accurately explains that cohesive change. Do not commit, push, rewrite history, or create a branch unless the user has authorized that action.

Before finishing a commit-related task:

1. Check the subject and any body against the reference.
2. Confirm that the message describes the committed diff rather than unrelated worktree changes.
3. Keep separate concerns in separate commits when the user has authorized multiple commits; otherwise explain why the current changes should be split.

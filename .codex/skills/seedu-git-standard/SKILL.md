# SE-EDU Git Standard

Use this skill whenever you create, amend, review, or propose a commit or branch in this repository.

Follow the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html):

- Write a subject line no longer than 72 characters, preferably 50 or fewer. Use imperative mood, capitalize the first word, and omit a final period. An optional meaningful scope or category may precede the subject.
- For non-trivial commits, separate the subject and body with a blank line. Wrap body lines at 72 characters and use blank lines or bullets to separate ideas.
- Explain what changed and why it changed, using present tense for the situation and imperative mood when describing the change. Do not spend the body explaining implementation mechanics that the diff already shows.
- Use a meaningful kebab-case branch name. For issue-related branches, use `issueNumber-keywords-from-issue-title`.

Before committing, check the subject length, mood, capitalization, punctuation, body wrapping, and branch name. Keep commits focused enough that the message can explain the rationale clearly.

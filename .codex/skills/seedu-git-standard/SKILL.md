# SE-EDU Git Standard

Use this skill for every commit, commit-message proposal or review, and branch-name
proposal or creation in this repository.

## Workflow

1. Read [references/git-standard.md](references/git-standard.md) before drafting or
   assessing Git wording.
2. Inspect the changes the commit will contain and any relevant issue or specification.
3. Write a message that accurately explains the commit's purpose and rationale. If the
   changes cannot be explained cohesively, recommend splitting them into smaller commits.
4. Audit the subject and body against every applicable rule in the reference. When
   creating a commit, audit the final message before running the commit command.

For branch names, inspect the related issue when one exists and audit the proposed name
against the branch-name rules in the reference.

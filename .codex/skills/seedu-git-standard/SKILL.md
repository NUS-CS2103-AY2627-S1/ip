# SE-EDU Git standard

Use this skill for all Git-related decisions in this repository.

## Source of truth

Follow the SE-EDU guide:

- https://se-education.org/guides/conventions/git.html

## Mandatory rules

- Use lightweight tags unless the user explicitly requests an annotated tag.
- Keep commit messages clear and specific; include enough detail to explain the rationale for the change.
- Do not commit or push unless the user explicitly asks for it.
- Prefer small, focused commits that reflect one change or one purpose.
- Do not rewrite shared history without explicit direction.
- Before finalizing a commit, review whether the changes are minimal and relevant to the task.
- When creating or proposing a commit message, explain the reason for the change and the affected behavior.

## Project-specific requirement

```text
Use $seedu-git-standard for all Git-related work in this project.
```

This applies to commit messages, tags, branch-related actions, and any Git workflow decisions in this repository.

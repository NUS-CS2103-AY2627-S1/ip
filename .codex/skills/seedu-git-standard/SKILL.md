# SE-EDU Git Standard

Follow the canonical [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html).

## Workflow

1. Read [references/rules.md](references/rules.md) before proposing or creating a commit message or branch name.
2. Inspect the actual staged or intended change before writing a commit message. Do not infer a rationale that the change does not support.
3. Check the proposed subject, body, or branch name against every applicable rule.
4. Correct violations before presenting or using the name or message.
5. Preserve the user's scope and authorization. This skill does not authorize committing, amending, branching, tagging, pushing, rebasing, or rewriting history.

When asked only for a suggested message or name, return a compliant suggestion without changing the repository.

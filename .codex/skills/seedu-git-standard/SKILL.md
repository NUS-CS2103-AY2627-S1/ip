# SE-EDU Git standard

Use this standard for every commit message in this project. Apply the SE-EDU [Git conventions](https://se-education.org/guides/conventions/git.html).

- Write an imperative, capitalized subject with no final period; aim for 50 characters and never exceed 72. A scope or category prefix is optional.
- For non-trivial commits, separate the subject from a body with a blank line and wrap body lines at 72 characters.
- Use the body to explain what changed and why, not how. Describe the current situation in present tense, the need for change, and the intended change in imperative mood. Use bullets when they improve clarity.
- Split unrelated changes into separate commits. Do not commit or push unless explicitly authorized.

# SE-EDU Git Standard

Follow the SE-EDU Git conventions for this project:
https://se-education.org/guides/conventions/git.html

## Commit Messages

- Write a clear subject line for every commit.
- Keep the subject near 50 characters where possible and under 72 characters.
- Use imperative mood, such as `Add JavaDoc comments`, not `Added JavaDoc`
  or `Adding JavaDoc`.
- Capitalize the first letter of the subject.
- Do not end the subject with a period.
- For non-trivial commits, include a body separated from the subject by a blank
  line.
- Wrap the body at 72 characters.
- Explain what changed and why it changed. Leave the exact implementation
  details to the diff unless they are important context.

## Branch Names

- Use meaningful branch names in kebab case.
- For CS2103T increment branches, preserve the assignment's requested names
  such as `branch-A-JavaDoc`, `branch-A-CodingStandard`, and `branch-Level-9`
  when the user is following those instructions.

Do not commit, tag, or push unless the user explicitly asks for it.

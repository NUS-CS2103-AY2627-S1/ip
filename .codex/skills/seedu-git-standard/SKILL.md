# SE-EDU Git Standard

Use this skill whenever proposing or creating a commit in this project. Follow
the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html).

- Write a subject of preferably 50 characters and at most 72 characters.
- Use imperative mood, capitalize the first letter, and do not end with a
  period. Add a useful scope or category when appropriate.
- For non-trivial commits, separate the subject and body with a blank line.
  Wrap body lines at 72 characters and use blank lines between paragraphs.
- Explain what changed and why, using present tense for the situation and
  imperative mood for the change. Do not explain implementation mechanics that
  the diff already makes clear.
- Split unrelated changes into separate commits so each commit has a focused
  purpose.

Before committing, check the subject length, grammar, punctuation, and whether
the body gives enough context for a reviewer to judge the change without
reading the diff.

# SE-EDU Git commit standard

Use this skill whenever creating or proposing a commit in this project.

- Write the subject in the imperative mood, capitalize its first letter, and do not end
  it with a period.
- Keep the subject at 50 characters when practical and never exceed 72 characters.
- Separate the subject from the body with one blank line.
- Add a body for non-trivial changes. Wrap body lines at 72 characters.
- Explain what changed and why it changed; do not narrate implementation steps.
- Keep each commit focused on one logical change. Use lightweight tags unless the user
  requests annotated tags.

Source: https://se-education.org/guides/conventions/git.html

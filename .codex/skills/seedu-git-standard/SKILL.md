# SE-EDU Git Standard

Apply the rules from https://se-education.org/guides/conventions/git.html

## Commit message: Subject

- Limit to 50 characters (hard limit: 72 chars)
- Use imperative mood ("Add feature", not "Added feature")
- Capitalize first letter
- No period at the end
- Optional prefix: `category: Description` (e.g., `bug fix: Add validation`)

## Commit message: Body

- Separate subject from body with a blank line
- Wrap body at 72 characters
- Explain WHAT and WHY, not HOW
- Use present tense for current situation, imperative for changes
- Use `Let's` to begin the change description
- Use bullet points when helpful

## Branch names

- Kebab-case: `refactor-ui-tests`
- Issue-related: `1234-ui-freeze-error`

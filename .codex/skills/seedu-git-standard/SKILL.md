# SE-EDU Git standard

For every commit in this repository:

- Write a clear subject in imperative mood, capitalize its first letter, omit the final period, and keep it at most 72 characters (prefer 50).
- Use an optional concise scope or category when useful.
- Give non-trivial commits a body separated from the subject by a blank line, wrapping body lines at 72 characters.
- Explain what changed and why; do not describe implementation steps that the diff already shows.

Authoritative standard: https://se-education.org/guides/conventions/git.html

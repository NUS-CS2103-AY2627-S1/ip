# SE-EDU Git Standard

Read [references/git-conventions.md](references/git-conventions.md) in full
before proposing, creating, or reviewing a commit message or branch name.

Base a commit message on the actual diff and repository state. Do not infer
permission to commit or push from a request to draft or review a message; obey
the repository's authorization rules.

Before using a proposed message, verify its subject length, imperative mood,
capitalization, punctuation, and its body where the commit is non-trivial.
Prefer multiple focused commits when one message would need to explain
unrelated changes. Explicit user-supplied branch names take precedence over the
default branch-naming convention.

# SE-EDU Git standard

Apply these rules whenever proposing or creating a commit:

- Write the subject in imperative mood and capitalize its first letter.
- Do not end the subject with a period.
- Prefer at most 50 characters for the subject; never exceed 72 characters.
- For non-trivial changes, separate the body from the subject with a blank line and wrap body lines at 72 characters.
- Explain what changed and why it was needed; leave implementation details to the diff.
- Split unrelated changes into separate commits.

Use lightweight tags unless the user explicitly requests annotated tags.

# SE-EDU Git Standard

Read and apply [references/standard.md](references/standard.md) before proposing or creating a commit message or branch name in this repository.

Before preparing a commit:

1. Inspect the actual changes so the message accurately describes the commit.
2. Keep each commit logically focused. If the required explanation becomes too long or covers unrelated changes, recommend splitting the commit.
3. Draft a compliant subject and, for every non-trivial commit, a body that explains what changed and why.
4. Check the final message's line lengths and wording against the reference.

This skill governs message quality and commit organization; it does not grant permission to create, amend, push, or otherwise mutate Git history. Follow `AGENTS.md` and obtain the authorization required for those actions.

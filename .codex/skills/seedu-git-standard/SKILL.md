# Git coding standard

Apply the SE-EDU Git conventions to all future commits. Every commit must have a clear subject in imperative mood, start with a capital letter, contain no final period, and ideally be at most 50 characters (hard limit 72 characters). A scope or category may be used when helpful.

For non-trivial changes, add a body separated from the subject by a blank line, wrap it at 72 characters, and explain what changed and why. Use bullet points when they improve clarity.

For details, consult https://se-education.org/guides/conventions/git.html

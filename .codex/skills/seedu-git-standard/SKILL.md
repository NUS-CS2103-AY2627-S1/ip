# SE-EDU Git commit standard

Use this skill for every commit in this repository.

- Write an imperative subject, capitalize its first letter, omit a final period, and keep it at or below 72 characters (prefer 50).
- Add a body for non-trivial changes, separated from the subject by a blank line.
- Wrap body lines at 72 characters and explain what changed and why; do not narrate implementation mechanics.
- Describe the current situation, the reason for change, the requested action, and relevant consequences.
- Split unrelated changes into separate commits when practical.

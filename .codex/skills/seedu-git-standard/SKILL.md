# SE-EDU Git standard

Apply this skill to all future commit-message proposals and commits in this
project. The authoritative guide is:
https://se-education.org/guides/conventions/git.html

For a commit subject:

- Write a clear subject, preferably within 50 characters and never over 72.
- Use imperative mood, capitalize the first letter, and do not end with a
  period. A concise scope or category prefix is allowed when useful.

For a non-trivial commit, add a body separated from the subject by one blank
line. Wrap body lines at 72 characters, separate paragraphs with blank lines,
and explain what changed and why. Describe the current situation in present
tense and the change in imperative mood; avoid explaining implementation details
that are already apparent from the diff.

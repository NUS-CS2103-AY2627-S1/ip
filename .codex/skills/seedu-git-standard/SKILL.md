# SE-EDU Git standard

Apply the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html) to every commit message in this repository.

- Write an imperative, capitalized subject with no period; target 50 characters and never exceed 72.
- For non-trivial commits, separate the subject and body with a blank line. Wrap body lines at 72 characters.
- Explain what the commit changes and why, in present tense for the current situation and imperative mood for the change. Use paragraphs or bullets when they improve clarity.
- Keep commits focused enough that the message can describe the change accurately without explaining implementation mechanics.

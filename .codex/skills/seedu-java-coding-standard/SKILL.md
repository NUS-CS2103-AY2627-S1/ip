# SE-EDU Java coding standard

Use this skill for all Java code changes in this repository.

- Keep all classes in a lower-case package and use PascalCase nouns for classes and enums.
- Use camelCase for variables and verb-style methods; use SCREAMING_SNAKE_CASE for constants.
- Use four spaces, K&R braces, explicit imports, and a hard maximum line length of 120 characters.
- Keep wrapped continuation lines readable and separate logical units with blank lines.
- Initialize variables at declaration when practical and keep them in the smallest useful scope.
- Always use braces for loops and conditionals, including single-statement bodies.
- Write English, American-spelling comments. Add descriptive Javadoc to public classes and public methods, except getters/setters and overridden methods when inherited documentation is exact.
- Follow the project’s existing package/source-root layout and run compilation/tests after Java changes.

For rules not covered here, follow the SE-EDU intermediate Java standard and the Google Java Style Guide.

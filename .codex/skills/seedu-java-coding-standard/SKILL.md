# SE-EDU Java Coding Standard

Read [references/java-conventions.md](references/java-conventions.md) in full
before changing or reviewing Java code.

Apply those rules to production code and tests. Preserve behavior unless the
task explicitly calls for a behavior change, and avoid unrelated formatting
churn.

Before finishing:

1. Check changed Java files for naming, layout, imports, control-flow braces,
   comments, and Javadocs.
2. Run `git diff --check` and confirm changed lines stay within the 120-character
   hard limit where Java syntax permits.
3. Follow the repository's Java 25 build and UI regression requirements.

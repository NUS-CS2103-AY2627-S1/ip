# SE-EDU Java Coding Standard

Apply these rules before finalising any Java change. Read
[`references/rules.md`](references/rules.md) for the compact, project-useful
summary of the SE-EDU standard.

## Workflow

1. Inspect changed Java files for violations of the referenced rules.
2. Use descriptive English names, standard whitespace, K&R braces, explicit
   imports, and the narrowest reasonable variable scope.
3. Add or update English Javadoc for public classes and public methods, except
   obvious getters/setters and overrides whose parent documentation applies.
4. Keep lines at or below 120 characters and use readable continuation
   indentation when wrapping.
5. Run the smallest relevant formatting or verification command when it is
   available; do not change behaviour solely to satisfy formatting.

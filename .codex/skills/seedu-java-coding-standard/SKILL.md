# SE-EDU Java Coding Standard

Apply this skill to every Java code change and Java code review in this repository.

Before working on Java code, read [references/standard.md](references/standard.md) completely. Use it as the review checklist for both production and test code. Fix violations in code within the user's requested scope without changing behavior unless the request also calls for a behavior change.

For a topic not covered by the project reference, follow the [Google Java Style Guide](https://google.github.io/styleguide/javaguide.html), as directed by the source standard. Higher-priority project instructions and explicit user requirements still take precedence.

Before finishing:

1. Recheck every changed Java file against the reference.
2. Confirm that no line exceeds 120 characters and that indentation uses spaces only.
3. Run the tests required by `AGENTS.md`.

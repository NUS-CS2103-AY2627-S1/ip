# SE-EDU Java Coding Standard

Use this skill for every change or review involving Java code in this repository.

## Workflow

1. Read [the project rules](references/java-coding-standard.md) before editing Java files.
2. Apply every rule that is relevant to the changed code. Use the Google Java Style Guide for topics the SE-EDU standard does not cover.
3. Review surrounding code touched by the change and correct nearby violations when doing so is low risk.
4. Before finishing, inspect all changed Java lines for naming, indentation, wrapping, braces, whitespace, imports, declaration scope, and Javadoc compliance.
5. Run the project-required JUnit and UI tests after any Java code change.

Do not alter program behavior merely to satisfy a formatting rule. If a rule is ambiguous, preserve behavior and choose the clearest consistent style.

# SE-EDU Java coding standard

Apply these conventions to Java code in this repository:

- Use lowercase package names, PascalCase class and enum names, camelCase variables and methods, and SCREAMING_SNAKE_CASE constants.
- Use four spaces for indentation, K&R braces, consistent imports, and a hard line limit of 120 characters.
- Initialize variables at declaration when practical and keep them in the smallest useful scope.
- Use braces for every loop and conditional body, including single-statement bodies.
- Keep logical blocks separated by blank lines and write comments in English using American spelling.
- Add descriptive JavaDoc header comments to all classes and public methods, except getters/setters and overriding methods whose inherited documentation applies exactly.
- Keep JavaDoc summaries concise and begin method summaries with a verb such as `Returns`, `Adds`, or `Creates`.

Authoritative standard: https://se-education.org/guides/conventions/java/intermediate.html

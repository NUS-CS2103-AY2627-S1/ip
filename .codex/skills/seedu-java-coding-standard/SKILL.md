# Java coding standard

Apply the SE-EDU Java basic and intermediate conventions to all Java code in this project. Use the project name as the root package and keep package names lower case. Use PascalCase nouns for classes, camelCase verbs for methods, camelCase variables, and SCREAMING_SNAKE_CASE constants.

Use four-space indentation, K&R braces, consistent explicit imports, and keep lines within 120 characters. Use braces for all loop and conditional bodies, and make intentional switch fall-through explicit.

Write descriptive JavaDoc header comments for all public classes and methods. Include `@param`, `@return`, and `@throws` when useful. Comments must be in English using American spelling. Test methods may use `featureUnderTest_testScenario_expectedBehavior()`.

For details, consult https://se-education.org/guides/conventions/java/intermediate.html

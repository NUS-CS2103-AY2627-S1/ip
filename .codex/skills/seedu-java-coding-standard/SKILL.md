# SE-EDU Java coding standard

Apply the rules in the [SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html) to every Java change in this repository. Use the project package structure and Java 25 configuration.

Check, as applicable:

- lower-case packages; PascalCase types; camelCase variables and methods; SCREAMING_SNAKE_CASE constants; boolean names that read naturally;
- four-space indentation, K&R braces, spaces around operators and after commas, consistent imports, explicit imports, and lines no longer than 120 characters;
- initialized variables in the smallest useful scope, private class fields unless they are constants or data-only fields, and braces around every loop and conditional body;
- English/American-spelling comments and descriptive Javadoc for public classes and public methods, except getters/setters, exact overrides, and tests.

For topics not covered here, follow the Google Java Style Guide referenced by the SE-EDU standard. Review the resulting diff for readability rather than applying mechanical formatting blindly.

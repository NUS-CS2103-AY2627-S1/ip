# SE-EDU Java Coding Standard

Apply the project rules summarized in [references/rules.md](references/rules.md) whenever creating, editing, or reviewing Java code in this repository.

## Workflow

1. Read the rules checklist before changing Java source or test files.
2. Apply the checklist to every touched Java file and inspect nearby code when the edit would otherwise leave an obvious violation in the same logical unit.
3. Preserve program behavior unless the user also requested a behavioral change.
4. Use the Google Java Style Guide only for topics the SE-EDU standard does not cover.
5. Before finishing, check package placement, imports, naming, line length, indentation, braces, whitespace, variable scope, and required Javadocs.
6. Run the JUnit and UI-test workflows required by `AGENTS.md` after Java changes.

Canonical source: <https://se-education.org/guides/conventions/java/intermediate.html>

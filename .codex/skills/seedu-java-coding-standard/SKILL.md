# SE-EDU Java coding standard

Use this skill whenever adding or modifying Java code in this project.

- Use lower-case package names and PascalCase class/enum names.
- Use camelCase for variables and methods, and SCREAMING_SNAKE_CASE for constants.
- Use four spaces for indentation, K&R braces, braces for every control statement, and
  no lines longer than 120 characters.
- Use explicit, consistently ordered imports; never use wildcard imports.
- Keep fields private unless they are constants or simple data-carrier fields.
- Declare and initialize variables in the smallest reasonable scope.
- Use whitespace around operators, after commas, and between logical code sections.
- Write comments and Javadoc in clear English. Add descriptive Javadoc to public classes
  and non-trivial public methods; include `@param`, `@return`, and `@throws` where useful.
- Name tests using `featureUnderTest_testScenario_expectedBehavior()` when a descriptive
  test name is helpful.

Source: https://se-education.org/guides/conventions/java/intermediate.html

# SE-EDU Java Coding Standard

Follow the project checklist in [references/coding-standard.md](references/coding-standard.md) whenever Java code is created, modified, or reviewed.

Treat the [SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html) as authoritative. For topics it does not cover, follow the Google Java Style Guide as directed by the SE-EDU standard.

## Workflow

1. Read the checklist before editing or reviewing Java code.
2. Inspect all Java lines affected by the change, including nearby code needed to keep formatting and naming consistent.
3. Correct applicable violations without changing behavior unless the task explicitly requires a behavior change.
4. Recheck changed Java files against the checklist before testing.
5. Follow the repository's required compilation and testing instructions in `AGENTS.md`.

Do not broaden a style-only task into unrelated refactoring. Preserve public behavior, file formats, and user-visible output unless the user requests otherwise.

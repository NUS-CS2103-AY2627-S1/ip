# SE-EDU Java Coding Standard

This skill shares its rules with the Claude Code skill in
`.claude/skills/seedu-java-coding-standard/`, so both tools hold the project to the same
standard. The rules themselves, and the commands that check code against them, live in
`.claude/skills/seedu-java-coding-standard/SKILL.md`. Read that file and apply it.

The rules come from <https://se-education.org/guides/conventions/java/intermediate.html> and
cover naming, layout, statements, and comments. They apply to every Java file in this project,
under `src/main/java` and `src/test/java` alike.

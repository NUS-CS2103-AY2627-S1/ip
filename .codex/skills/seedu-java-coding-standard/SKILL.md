# SE-EDU Java Coding Standard

Use this skill for every Java code change or review in this repository.

## Workflow

1. Read [references/coding-standard.md](references/coding-standard.md) before assessing or changing Java code.
2. Apply every relevant rule to the Java code in scope. Preserve behavior when the task is only a style correction.
3. Inspect the result for rules that formatters cannot reliably enforce, especially naming, package structure, declaration scope, import grouping, braces, and Javadocs.
4. Compile and test with Java 25. Report any intentional deviation and its reason.

When a user requests a repository-wide audit, inspect every Java file. For ordinary feature work, ensure all added or modified Java code complies and avoid unrelated rewrites.

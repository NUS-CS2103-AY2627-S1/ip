---
name: seedu-java-coding-standard
description: Apply the SE-EDU intermediate Java coding standard to Java source and test changes in this project.
---

Follow the SE-EDU Java basic and intermediate conventions: every class belongs to a lower-case project package; use PascalCase classes, camelCase methods/variables, SCREAMING_SNAKE_CASE constants, four-space indentation, K&R braces, explicit imports, and lines no longer than 120 characters. Use clear English Javadoc for public classes and methods, with concise first-sentence summaries and documented parameters, returns, and exceptions where useful. Name boolean fields and methods with `is`, `has`, `can`, or `should` prefixes. Use descriptive test names in the `featureUnderTest_testScenario_expectedBehavior` form. Refer to https://se-education.org/guides/conventions/java/intermediate.html for rules not summarized here.

# SE-EDU Git Standard

Use this project-specific skill whenever drafting, reviewing, or creating a
commit. Read [the local commit-message reference](../git-commit-messages/references/commit-message-standard.md)
before writing the message.

Use an imperative, capitalized subject with no trailing period; aim for 50
characters and never exceed 72. Non-trivial commits need a body separated by a
blank line, wrapped at 72 characters, that explains what changed and why.
Keep commits logically focused and inspect the staged diff before committing.

The source standard is the SE-EDU [Git convention](https://se-education.org/guides/conventions/git.html).

# Git commit standard

- Write an imperative, capitalized subject without a trailing period.
- Keep the subject at or below 50 characters when practical and never above
  72 characters.
- For non-trivial commits, separate the subject from a body wrapped at
  72 characters.
- Explain what changed and why; avoid narrating implementation mechanics.
- Use separate commits for unrelated changes.

Source: [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html).

# SE-EDU Git standard

Apply this skill whenever creating branches or preparing commits in this project.

## Branches

- Use meaningful kebab-case branch names such as `refactor-ui-tests`.
- When an issue number exists, use `issueNumber-keywords-from-issue-title`.

## Commit subjects

- Write a subject for every commit.
- Use imperative mood, capitalize the first letter, and omit the final period.
- Prefer 50 characters or fewer; never exceed 72 characters.
- Add a scope or category prefix when it clarifies the change.

## Commit bodies

- Add a body for non-trivial commits, separated from the subject by a blank line.
- Wrap body lines at 72 characters and use blank lines or bullets for separate points.
- Explain what changed and why; do not describe implementation steps that the diff already shows.
- Structure the body around the current situation, why it needs to change, what to do, and relevant rationale.

Reference: https://se-education.org/guides/conventions/git.html

# Git commit standard

Follow the [SE-EDU Git conventions](https://se-education.org/guides/conventions/git.html)
for every commit in this project.

Write an imperative subject, capitalize its first letter, omit a final period,
and keep it preferably within 50 characters (hard limit 72). Add a scope or
category only when useful.

For non-trivial commits, separate the subject and body with a blank line. Wrap
body lines at 72 characters and explain WHAT changed and WHY. Describe the
current situation in present tense, the change in imperative mood, and use
blank lines or bullets when they improve readability.

Before committing, review the proposed subject and body against these rules.

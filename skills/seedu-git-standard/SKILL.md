# SE-EDU Git Standard

Use the SE-EDU conventions at https://se-education.org/guides/conventions/git.html for future Git work in this project.

Use meaningful kebab-case branch names. Commit subjects should be concise imperative summaries, normally under 72 characters, with a blank line before a body. Explain what changed and why in present tense and imperative mood; keep commits focused and split unrelated changes. Do not commit generated files. When proposing a commit, describe the rationale sufficiently for review without repeating implementation details.

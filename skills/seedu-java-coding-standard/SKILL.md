# SE-EDU Java Coding Standard

Use the SE-EDU intermediate conventions at https://se-education.org/guides/conventions/java/intermediate.html for all Java code in this project.

Keep classes in meaningful packages, use explicit consistently ordered imports, and organize class members as documentation, declaration, static fields, instance fields, constructors, then methods. Put access modifiers first, attach array brackets to the type, initialize variables where practical, keep scope narrow, and avoid public class variables. Prefer clear nouns for classes and variables and verbs for methods. Preserve local consistency and add Javadoc for public APIs and non-trivial behavior.

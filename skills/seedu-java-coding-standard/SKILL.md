# SE-EDU Java coding standard

Apply this skill to all Java production and test code in this project.

- Keep packages lowercase; use PascalCase for classes and enums, camelCase for methods and variables, and SCREAMING_SNAKE_CASE for constants.
- Use four spaces for indentation, K&R braces, explicit imports, and no wildcard imports.
- Keep lines at or below 120 characters, wrapping long lines with continuation indentation of eight spaces.
- Put braces around every loop and conditional body, including single-statement bodies.
- Keep one logical statement per line and separate logical blocks with a blank line.
- Use descriptive JavaDoc for every public class and public method, including `@param`, `@return`, and `@throws` where useful. Document non-trivial private methods and fields.
- Use the test method naming form `featureUnderTest_testScenario_expectedBehavior()` when names need multiple components.
- Prefer readable, explicit code over clever compact formatting.

Use the authoritative standard for details not listed here:
https://se-education.org/guides/conventions/java/intermediate.html

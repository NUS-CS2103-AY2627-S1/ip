# Java coding standard

Apply the SE-EDU basic and intermediate Java conventions:

- Keep every class in a lower-case package such as `duke`.
- Use PascalCase nouns for classes and enums, camelCase verbs for methods,
  camelCase for variables, and SCREAMING_SNAKE_CASE for constants.
- Use four-space indentation, K&R braces, explicit imports, and a 120-character
  hard line limit (prefer shorter lines).
- Wrap loop and conditional bodies in braces and separate logical code units
  with blank lines.
- Initialize variables at declaration when practical and keep scope narrow.
- Write descriptive English Javadoc for public classes and methods; document
  parameters, return values, and exceptions when they add useful information.
- Test method names may use the three-part
  `featureUnderTest_testScenario_expectedBehavior` form.

Source: [SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html).

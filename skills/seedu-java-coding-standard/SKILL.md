# Java coding standard

Follow the [SE-EDU Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html)
for all Java code in this project. Use the project name as the root package and
lowercase logical subpackages. Use PascalCase for classes and enums, camelCase
for variables and methods, and SCREAMING_SNAKE_CASE for constants.

Use four spaces for indentation, K&R braces, explicit imports, and keep lines
within 120 characters. Always use braces for loops and conditionals. Keep
variables in the smallest practical scope and preserve encapsulation.

Write descriptive Javadoc for every class and public method, except getters,
setters, and overriding methods when the inherited documentation applies.
Use English, American spelling, and clear method descriptions.

Before finishing Java work, compile the project and inspect the diff for unused
imports, wildcard imports, long lines, missing braces, and missing Javadoc.

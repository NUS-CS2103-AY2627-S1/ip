# SE-EDU Git standard

Apply the conventions documented at https://se-education.org/guides/conventions/git.html.

- Use meaningful kebab-case branch names, with an issue number prefix when applicable.
- Write commit subjects in imperative mood, capitalize the first letter, omit the final period, and keep them within 72 characters (preferably 50).
- Give every non-trivial commit a body separated from the subject by a blank line; wrap body lines at 72 characters.
- Explain what changed and why, using present tense for the current situation and imperative mood for the change.
- Use bullets in the body when they improve clarity.
- Do not commit or push unless the user authorizes it.

Use the linked SE-EDU guide for details not covered here.

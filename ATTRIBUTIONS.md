# Attributions

## Project template and tutorials

This project started from the NUS CS2103 project template:
<https://github.com/NUS-CS2103-AY2627-S1/ip>.

The inherited template includes the project setup documentation, contributor
information, Gradle setup, and JavaFX tutorial material. The JavaFX GUI in this
project was developed with the GUI structure and examples from the inherited
Duke tutorials as reference, especially the tutorials on creating a GUI and
interacting with the user.

## Mascot artwork

The Dingleberry mascot artwork in
`src/main/resources/dingleberry/dingleberry_avatar.png` was generated using
ChatGPT by the project author. The
`dingleberry_mascot_crop.png` asset is a crop derived from that generated
artwork for use in the application header and dialog cards.

## Third-party tooling and libraries

The project uses the following third-party tools and libraries, identified in
`build.gradle` and the Gradle wrapper configuration:

- Gradle, including the generated Gradle wrapper scripts.
- OpenJFX JavaFX modules.
- JUnit Jupiter and the JUnit Platform.
- JaCoCo.
- Checkstyle.
- The Shadow Gradle plugin.

Their respective upstream project pages and licence terms apply. The Gradle

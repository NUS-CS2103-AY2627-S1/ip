## Java coding standard

All Java code in this project, including tests, must follow
[`skills/seedu-java-coding-standard`](skills/seedu-java-coding-standard/SKILL.md),
based on the SE-EDU basic + intermediate Java coding standard. Apply it to
every Java review or change.

## Git standard

All future commits must follow
[`skills/seedu-git-standard/SKILL.md`](skills/seedu-git-standard/SKILL.md),
based on the SE-EDU Git conventions. Apply it before proposing or creating any
commit; do not commit or push unless explicitly authorized.

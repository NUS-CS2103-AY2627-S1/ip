# SE-EDU Git Standard

Use the SE-EDU Git conventions for every commit message and branch name in this repository.

Before proposing, reviewing, or creating either one, read
[references/git-standard.md](references/git-standard.md). Inspect the relevant status and diff so
the message describes the actual change. Keep each commit focused on one coherent purpose; flag
unrelated changes that should be committed separately.

This skill does not authorize a commit, amend, push, tag, or branch operation. Obtain the authority
required by `AGENTS.md` before changing Git state.

Before finishing a Git operation:

1. Validate the subject, body when required, and branch name against the reference.
2. If a commit was authorized and created, inspect its final message and report it accurately.
3. Do not amend a non-compliant existing commit without explicit permission; explain the issue and
   propose a compliant replacement message.

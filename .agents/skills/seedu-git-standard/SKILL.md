# SE-EDU Git standard

Apply these rules whenever creating, amending, or proposing a commit or branch in this repository.

- Write a clear commit subject in imperative mood, capitalize its first letter, omit the final period, and keep it preferably within 50 characters and never over 72 characters. A concise scope or category prefix is allowed when useful.
- For non-trivial commits, separate the subject from a body with a blank line. Wrap body lines at 72 characters, use paragraphs or bullets where helpful, and explain what changed and why—not how. Describe the situation and reason in present tense, then state the change in imperative mood.
- Use meaningful branch names in kebab-case. For issue work, use `issueNumber-keywords-from-issue-title`.
- Do not commit or push unless the user explicitly asks. When proposing a commit message, include enough detail to explain the rationale.

Source: https://se-education.org/guides/conventions/git.html

# SE-EDU Git Standard

Use these conventions for every commit:

- Write an imperative, capitalized subject line with no trailing period.
- Keep the subject at 50 characters where possible and never exceed 72.
- Add a body for non-trivial changes, separated from the subject by a blank
  line and wrapped at 72 characters.
- Explain what changes and why they are useful, rather than restating the
  implementation details visible in the diff.
- Use bullets when they clarify several related changes.
- Keep commits focused: make a separate commit for independent source,
  documentation, or agent-guidance changes.

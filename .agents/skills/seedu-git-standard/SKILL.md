# SE-EDU Git Standard

Apply the project rules in [references/standard.md](references/standard.md) whenever preparing, proposing, reviewing, or creating a commit or branch.

Before proposing or creating a commit:

1. Read the reference completely.
2. Inspect the actual diff and status so the message describes only the changes included in the commit.
3. Keep each commit cohesive. If a message needs an overly long explanation, recommend splitting the work into smaller commits.
4. Check the subject and body against the length, tense, capitalization, punctuation, and content rules.
5. Do not commit or push unless the user explicitly authorizes it.

Preserve repository-specific Git requirements in `AGENTS.md`, including lightweight tags unless the user requests an annotated tag.

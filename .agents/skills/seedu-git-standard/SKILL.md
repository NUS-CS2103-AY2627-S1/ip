# SE-EDU Git Standard

This skill mandates Git conventions based on [SE-EDU Git Conventions](https://se-education.org/guides/conventions/git.html).

## 1. Branch Naming Conventions

- Use `kebab-case` for branch names.
- Name feature branches after increments or tasks (e.g., `branch-A-CodingStandard`, `branch-Level-9`).

## 2. Commit Message Guidelines

- **Imperative Mood**: Use imperative mood in the subject line (e.g., "Add JavaDoc comments", "Refactor TaskList to use guard clauses", NOT "Added..." or "Adds...").
- **Capitalization**: Capitalize the first letter of the subject line.
- **No Trailing Period**: Do NOT end the subject line with a period `.`.
- **Subject Length**: Limit the subject line to 50 characters maximum.
- **Message Body** (if needed):
  - Separate subject from body with a blank line.
  - Wrap lines in the body at 72 characters.
  - Explain *what* changed and *why*, rather than *how*.

# SE-EDU Java coding standard

Use the [SE-EDU basic and intermediate Java coding standard](https://se-education.org/guides/conventions/java/intermediate.html)
for every Java code change or review in this project. For topics the standard does not
cover, follow the Google Java Style Guide as directed by SE-EDU.

Before editing or reviewing Java, read [references/rules.md](references/rules.md)
completely and apply its checklist to both the changed lines and closely related code.

Preserve application behavior during formatting and documentation-only work. Do not
rename public APIs or redesign code merely to enforce a subjective preference when the
existing form is permitted by the standard.

Before finishing:

1. Check naming, imports, indentation, wrapping, braces, whitespace, and Javadocs.
2. Confirm no Java line exceeds 120 characters and prefer at most 110 characters.
3. Run the Java 25 verification required by the project `AGENTS.md`.
4. If application behavior or console output changed, follow the project console UI
   testing instructions as well.

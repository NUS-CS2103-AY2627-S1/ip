# SE-EDU Java Coding Standard

Use the SE-EDU basic and intermediate rules for every Java change in this repository.

Before editing or reviewing Java, read [references/coding-standard.md](references/coding-standard.md).
Apply every relevant rule to all Java files in scope, including tests. For topics the reference does
not cover, follow the Google Java Style Guide unless it conflicts with an SE-EDU rule.

Before finishing:

1. Check names, imports, indentation, wrapping, braces, variable scope, and JavaDoc against the
   reference.
2. Ensure no changed Java line exceeds 120 characters and no tab is used for indentation.
3. Run the project's JavaDoc, compilation, and test tasks required by `AGENTS.md`.
4. Report any deliberate exception to the standard and its reason.

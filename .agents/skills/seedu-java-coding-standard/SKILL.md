# SE-EDU Java Coding Standard

Apply the repository's required Java conventions consistently to production
code and tests.

## Workflow

1. Read `references/conventions.md` completely before changing or reviewing
   Java code.
2. Inspect the relevant Java files before editing so that local naming and
   abstractions remain consistent.
3. Apply the standard to all added or changed Java lines. When asked for a
   project-wide compliance pass, also correct existing violations elsewhere.
4. Use the Google Java Style Guide for topics not covered by the SE-EDU rules.
5. Keep behavior unchanged when the task is purely a style or documentation
   update.
6. Run the project's required Gradle and UI checks after application-code
   changes, as specified in `AGENTS.md`.

When a rule and the user's explicit requirement conflict, follow the user and
call out the exception in the handoff.

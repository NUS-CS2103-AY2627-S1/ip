# SE-EDU Java Coding Standard

Apply the project rules in [references/standard.md](references/standard.md) to every Java code change and review.

Before editing Java code, read the reference completely. Preserve behavior unless the user requests a behavior change. After editing:

1. Review every changed Java line against the reference.
2. Check the full changed files for related formatting or documentation inconsistencies.
3. Keep lines within 120 characters, aiming for fewer than 110.
4. Run the relevant Gradle tests using Java 25.

When a rule does not cover a topic, follow the Google Java Style Guide unless it conflicts with repository instructions or the user's request.

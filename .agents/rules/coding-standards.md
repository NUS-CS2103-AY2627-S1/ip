# Project Coding & Git Standards Rule

All Java code and Git commits in this project MUST strictly follow the project skills:

1. **Java Code**: Follow `seedu-java-coding-standard` (.agents/skills/seedu-java-coding-standard/SKILL.md)
   - Explicit imports (no wildcards)
   - 4-space indentation and 120-char line limit
   - Strict naming conventions (PascalCase, camelCase, UPPER_SNAKE_CASE)
   - Proper member ordering and guard clause usage

2. **Git Commit Messages**: Follow `seedu-git-standard` (.agents/skills/seedu-git-standard/SKILL.md)
   - Use imperative mood in subject lines
   - Capitalize first letter, no trailing period, max 50 chars for subject

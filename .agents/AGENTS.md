# Project UI testing

For all Java code in this repository, follow
`skills/seedu-java-coding-standard/SKILL.md`. For every future commit, follow
`skills/seedu-git-standard/SKILL.md`.

After every code update, review and update `test/ui-test-plan.md` when commands,
behavior, or expected output have changed, then invoke `.agents/skills/test-ui/SKILL.md`.
The skill prints console input and output, stops at the first failure, and reports
both actual and expected output.

## Fixes and compatibility

- Extracted `MainView` from `Main`, reducing `Main` from 592 to 324 lines.
  Split long command, layout, storage, and message-building methods into focused steps.
- Improved Javadoc summaries and the `isNumbered` boolean name.
- Preserved escaped line breaks at field edges when reading saved tasks.
  Rejected blank decoded fields with line-specific recovery advice.
- Kept domain deadline years within the four-digit range supported by parsing
  and storage, preventing a programmatically added task from creating an unreadable save.
- Kept saves and JavaFX extraction inside the launch folder, as required by the
  [Week 6 writing constraint](https://nus-cs2103-ay2627-s1.github.io/website/admin/ip-w6.html).
  Native libraries use a fixed cache and unchanged copies are not rewritten.
- Updated the guide, quick start, architecture, and test plan. Ignored local
  runtime caches, scratch folders, and root-level downloaded JARs.

The task command syntax and save-file format are unchanged. Launching from the
folder containing the JAR and existing `data` folder retains the same task file.
Unlike v0.7, launching from another folder uses that folder's data and cache;
it does not relocate or overwrite files beside a JAR stored elsewhere.

python3 tests/release_smoke.py build/libs/Wangsa.jar build/distributions/Wangsa.zip

- **113 JUnit cases passed**, with zero failures, errors, or skips.
- Checkstyle, Javadoc, compilation, fat-JAR packaging, ZIP contents, and

- Packaged GUI scenarios passed on this Mac: normal commands, reload, invalid
